# 부산 AI·DX 지원사업 문의 포털 PRD

## 1. 목적

이 웹페이지는 부산 지역기업과 시민이 부산정보산업진흥원의 AI·DX 관련 지원사업에 대해 문의를 작성하고, 등록된 문의 목록을 확인하며, 문의 데이터를 엑셀 파일로 가져오거나 내보낼 수 있는 단일 화면 문의 포털이다.

페이지의 첫 화면에서 사용자는 다음을 즉시 확인할 수 있어야 한다.

- 서비스명: `부산 AI·DX 지원사업 문의 포털`
- 서비스 설명: `지역기업·시민 누구나 부산정보산업진흥원의 지원사업에 문의할 수 있는 창구입니다.`
- 문의 작성 영역
- 문의 목록 영역
- 현재 등록된 문의 건수
- 엑셀 가져오기와 엑셀 내보내기 기능

이 페이지는 별도 회원가입, 로그인, 메뉴 이동 없이 한 화면에서 문의 등록, 조회, 삭제, 엑셀 입출력을 모두 수행하는 것을 목적으로 한다.

## 2. 사용자

주 사용자는 부산정보산업진흥원의 AI·DX 지원사업에 관심이 있는 지역기업 담당자, 예비 창업자, 스타트업 구성원, 콘텐츠 제작자, 교육 신청 희망자, 일반 시민이다.

사용자는 다음 상황에서 이 페이지를 이용한다.

- 제조 현장, 업무 프로세스, 서비스에 AI·DX 솔루션을 도입하고 싶어 지원 가능 여부를 문의한다.
- 데이터 구매, 데이터 가공, 클라우드 이용 바우처 신청 일정이나 준비 서류를 문의한다.
- AI 교육과정, 재직자 교육, 인재양성 프로그램의 일정과 신청 방법을 문의한다.
- 스타트업 입주 공간, 창업 지원, 센텀 지역 입주 조건을 문의한다.
- 게임·콘텐츠 제작비 지원사업의 신청 절차와 평가 방식을 문의한다.
- 해외진출 지원사업 또는 기타 지원사업에 대해 문의한다.

관리 성격의 사용자도 같은 화면에서 문의 목록을 확인하고, 불필요한 문의를 삭제하며, 문의 목록을 엑셀로 내보내거나 기존 엑셀 데이터를 가져올 수 있다.

## 3. 핵심 기능

### 문의 작성

사용자는 `문의 작성` 섹션에서 새 문의를 등록할 수 있어야 한다.

문의 작성 폼은 위에서 아래 순서로 다음 입력 항목을 제공해야 한다.

- `카테고리` 선택 필드
- `이름` 입력 필드
- `제목` 입력 필드
- `내용` 입력 영역
- `등록하기` 버튼

`카테고리` 선택 필드는 기본값으로 `AI·DX 솔루션 도입`을 표시해야 하며, 선택 가능한 항목은 다음 순서로 제공해야 한다.

1. `AI·DX 솔루션 도입`
2. `데이터·클라우드 바우처`
3. `교육·인재양성 신청`
4. `스타트업 입주·창업`
5. `게임·콘텐츠 제작 지원`
6. `해외진출`
7. `기타`

`이름` 입력 필드는 한 줄 텍스트 필드이며 placeholder로 `작성자 이름`을 표시해야 한다.

`제목` 입력 필드는 한 줄 텍스트 필드이며 placeholder로 `문의 제목을 입력하세요`를 표시해야 한다.

`내용` 입력 영역은 여러 줄 입력이 가능해야 하며 초기 높이는 약 5줄 분량이어야 한다. placeholder로 `지원사업 문의 내용을 작성하세요`를 표시해야 한다.

`이름`, `제목`, `내용`은 필수 입력값이다. 사용자가 `등록하기` 버튼을 누르면 새 문의가 목록에 추가되어야 한다.

문의 등록 후 화면은 다음처럼 동작해야 한다.

- 작성 폼의 입력값을 초기화한다.
- 카테고리는 다시 `AI·DX 솔루션 도입`으로 돌아간다.
- 제목 입력 필드에 포커스를 둔다.
- 문의 목록의 총 건수를 즉시 갱신한다.
- 새 문의는 목록의 가장 위에 표시한다.
- 새 문의의 시간 표시는 등록 직후 `방금`으로 표시한다.

### 문의 목록 조회

`문의 목록` 섹션은 등록된 문의를 최신순으로 보여줘야 한다.

목록 상단에는 현재 문의 수를 `총 N건` 형식으로 표시해야 한다. 초기 상태에서는 샘플 문의 5건이 있으므로 `총 5건`으로 시작한다.

각 문의 항목은 카드 형태로 표시해야 하며, 카드 안에는 다음 정보가 보여야 한다.

- 카테고리 배지
- 상대 등록 시간
- 문의 제목
- 작성자
- 삭제 버튼
- 문의 내용

카테고리 배지는 연한 하늘색 배경과 진한 파란색 글자로 표시한다. 배지 텍스트는 해당 문의의 카테고리명과 동일해야 한다.

상대 등록 시간은 현재 시각을 기준으로 다음 규칙에 따라 표시한다.

- 1분 미만: `방금`
- 1분 이상 60분 미만: `N분 전`
- 1시간 이상 24시간 미만: `N시간 전`
- 24시간 이상: `N일 전`

작성자는 `작성자 이름` 형식이 아니라, `작성자 김민준`처럼 `작성자`라는 라벨 뒤에 이름을 붙여 표시한다.

문의 내용은 카드 하단에 본문 텍스트로 표시하며, 줄 간격은 넉넉하게 유지해 긴 문장도 읽기 쉬워야 한다.

등록된 문의가 하나도 없으면 목록 영역에는 카드 대신 다음 문구를 중앙 정렬로 표시해야 한다.

`등록된 문의가 없습니다.`

이 빈 상태 문구는 점선 테두리, 연한 회색 배경, 회색 텍스트로 표시한다.

### 초기 샘플 문의

페이지 최초 진입 시 문의 목록에는 아래 5개 샘플 문의가 표시되어야 한다. 표시 순서는 최신순이어야 한다.

1. 카테고리: `AI·DX 솔루션 도입`
   제목: `AI 솔루션 실증 비용 지원 가능한가요?`
   작성자: `김민준`
   내용: `제조 현장에 영상 분석 AI 솔루션을 시범 적용하려고 합니다. 실증 비용이나 컨설팅을 함께 지원받을 수 있는 사업이 있는지 문의드립니다.`
   시간: 현재 시각 기준 `방금`

2. 카테고리: `데이터·클라우드 바우처`
   제목: `데이터 바우처 신청 기간이 언제인가요?`
   작성자: `박서연`
   내용: `올해 데이터 구매 및 가공 바우처 신청 일정과 준비해야 할 서류가 궁금합니다.`
   시간: 현재 시각 기준 약 `3분 전`

3. 카테고리: `스타트업 입주·창업`
   제목: `센텀 스타트업 입주 자격 문의`
   작성자: `이도윤`
   내용: `초기 창업팀도 센텀 지역 입주 공간에 신청할 수 있는지, 평가 기준과 입주 기간을 알고 싶습니다.`
   시간: 현재 시각 기준 약 `12분 전`

4. 카테고리: `게임·콘텐츠 제작 지원`
   제목: `Bu:Star 게임 제작비 신청 절차`
   작성자: `최하린`
   내용: `모바일 게임 프로토타입을 개발 중입니다. Bu:Star 제작비 지원사업의 신청 절차와 발표 평가 방식이 궁금합니다.`
   시간: 현재 시각 기준 약 `28분 전`

5. 카테고리: `교육·인재양성 신청`
   제목: `AI 활용 교육과정 일정 안내 부탁드립니다`
   작성자: `정유진`
   내용: `재직자 대상 AI 활용 교육과정이 개설되는 일정과 온라인 수강 가능 여부를 안내받고 싶습니다.`
   시간: 현재 시각 기준 약 `55분 전`

### 문의 삭제

각 문의 카드 우측 상단에는 `삭제` 버튼이 있어야 한다.

사용자가 `삭제` 버튼을 누르면 해당 문의는 목록에서 즉시 제거되어야 한다. 별도 확인 모달이나 알림 없이 삭제가 완료된다.

삭제 후에는 다음 상태가 즉시 갱신되어야 한다.

- 문의 목록
- `총 N건` 문의 수
- 문의가 0건이 된 경우의 빈 상태 문구

### 엑셀 내보내기

`문의 목록` 섹션 상단 오른쪽에는 `엑셀 내보내기` 버튼이 있어야 한다.

사용자가 버튼을 누르면 현재 문의 목록 전체를 최신순으로 정렬해 `.xlsx` 파일로 다운로드해야 한다.

다운로드 파일명은 `문의_목록_YYYY-MM-DD.xlsx` 형식을 사용한다. 예를 들어 2026년 5월 28일에 내보내면 `문의_목록_2026-05-28.xlsx`로 저장된다.

엑셀 파일의 시트명은 `문의목록`이어야 한다.

엑셀 파일은 다음 열을 이 순서대로 포함해야 한다.

1. `ID`
2. `카테고리`
3. `제목`
4. `작성자`
5. `내용`
6. `등록일시`

`등록일시`는 `YYYY-MM-DD HH:mm` 형식으로 기록한다.

엑셀 내보내기가 성공하면 목록 상단 아래에 상태 메시지를 표시해야 한다.

`문의 N건을 엑셀 파일로 내보냈습니다.`

성공 상태 메시지는 연한 하늘색 배경과 진한 파란색 텍스트로 표시한다.

엑셀 처리 라이브러리를 사용할 수 없는 경우에는 다음 오류 메시지를 표시해야 한다.

`엑셀 라이브러리를 불러오지 못했습니다. 네트워크 연결을 확인해 주세요.`

오류 상태 메시지는 연한 빨간색 배경과 진한 빨간색 텍스트로 표시한다.

### 엑셀 가져오기

`문의 목록` 섹션 상단 오른쪽에는 `엑셀 가져오기` 버튼이 있어야 한다. 이 버튼은 파일 선택 창을 열어야 하며, 사용자는 `.xlsx` 또는 `.xls` 파일을 선택할 수 있어야 한다.

엑셀 파일에서 첫 번째 시트를 읽어 문의 데이터를 가져온다.

가져오기 대상 열은 한글 열명과 영문 키를 모두 허용해야 한다.

- 카테고리: `카테고리` 또는 `category`
- 제목: `제목` 또는 `title`
- 작성자: `작성자` 또는 `author`
- 내용: `내용` 또는 `body`
- 등록일시: `등록일시` 또는 `createdAt`

가져온 데이터 중 `제목`, `작성자`, `내용`이 모두 있는 행만 문의로 등록한다.

카테고리가 비어 있으면 `기타`로 등록한다.

등록일시가 비어 있거나 읽을 수 없는 값이면 현재 시각으로 등록한다.

엑셀에서 가져온 문의는 기존 문의 뒤에 추가되며, 화면 표시 시에는 등록일시 기준 최신순으로 정렬되어야 한다.

가져오기 성공 시 목록 상단 아래에 다음 상태 메시지를 표시해야 한다.

`엑셀에서 문의 N건을 가져왔습니다.`

가져올 수 있는 문의가 없으면 다음 오류 메시지를 표시해야 한다.

`가져올 수 있는 문의가 없습니다. 제목, 작성자, 내용 열을 확인해 주세요.`

엑셀 파일을 읽는 중 오류가 발생하면 다음 오류 메시지를 표시해야 한다.

`엑셀 파일을 읽는 중 오류가 발생했습니다. 파일 형식을 확인해 주세요.`

엑셀 처리 라이브러리를 사용할 수 없는 경우에는 다음 오류 메시지를 표시해야 한다.

`엑셀 라이브러리를 불러오지 못했습니다. 네트워크 연결을 확인해 주세요.`

## 4. 화면 구성

### 전체 레이아웃

페이지는 흰색 배경의 단일 페이지로 구성한다. 콘텐츠는 화면 중앙에 배치하며, 최대 너비는 약 1024px 수준으로 제한한다.

전체 화면은 위에서 아래로 다음 순서로 배치한다.

1. 헤더
2. 메인 콘텐츠
3. 문의 작성 섹션
4. 문의 목록 섹션

헤더와 메인 콘텐츠는 좌우 여백을 유지해야 한다. 모바일 화면에서도 콘텐츠가 화면 가장자리에 붙지 않도록 좌우 여백을 둔다.

### 헤더

헤더는 페이지 최상단에 위치하며 흰색 배경과 하단 경계선을 가진다.

헤더 내부에는 제목 행과 설명 문구가 있다.

제목 행은 왼쪽에 세로 파란 막대, 오른쪽에 서비스명을 배치한다.

- 세로 막대: 진한 파란색, 폭 약 6px, 높이 약 36px, 모서리는 둥글게 처리
- 제목 텍스트: `부산 AI·DX 지원사업 문의 포털`
- 제목 크기: 데스크톱에서 약 30px, 모바일에서 약 24px
- 제목 두께: 매우 굵게 표시

설명 문구는 제목 아래에 표시한다.

- 문구: `지역기업·시민 누구나 부산정보산업진흥원의 지원사업에 문의할 수 있는 창구입니다.`
- 색상: 중간 회색
- 위치: 제목의 파란 막대와 정렬되도록 왼쪽 여백을 약간 둔다.

### 문의 작성 섹션

문의 작성 섹션은 메인 콘텐츠의 첫 번째 박스이다.

섹션 스타일은 다음과 같다.

- 연한 회색 계열 배경
- 옅은 회색 테두리
- 약한 그림자
- 8px 수준의 둥근 모서리
- 내부 여백 약 20px
- 아래쪽에 문의 목록 섹션과 구분되는 간격

섹션 상단에는 왼쪽에 `문의 작성` 제목을 표시한다.

데스크톱 또는 태블릿 폭에서는 오른쪽에 보조 배지 `AI·DX 지원사업 상담`을 표시한다. 이 배지는 흰색 배경, 진한 파란색 텍스트, 옅은 테두리로 표시한다. 모바일 폭에서는 이 배지를 숨긴다.

폼 배치는 다음 규칙을 따른다.

- 데스크톱 폭에서는 `카테고리`와 `이름`을 같은 행에 2열로 배치한다.
- 모바일 폭에서는 `카테고리`와 `이름`을 세로로 쌓는다.
- `제목`은 한 행 전체 폭을 사용한다.
- `내용`은 한 행 전체 폭을 사용한다.
- `등록하기` 버튼은 폼 하단 오른쪽에 배치한다.

모든 입력 필드는 높이 약 44px의 한 줄 필드로 표시한다. `내용` 입력 영역은 여러 줄 높이를 가진다.

입력 필드는 흰색 배경, 옅은 회색 테두리, 8px 수준의 둥근 모서리를 사용한다. 포커스 시 테두리는 밝은 하늘색으로 바뀌고, 옅은 하늘색 포커스 링이 나타나야 한다.

`등록하기` 버튼은 진한 파란색 배경, 흰색 굵은 글자, 높이 약 44px로 표시한다. 버튼에 마우스를 올리면 더 어두운 파란색으로 바뀐다.

### 문의 목록 섹션

문의 목록 섹션은 문의 작성 섹션 아래에 위치한다.

섹션 전체는 흰색 배경, 옅은 회색 테두리, 8px 수준의 둥근 모서리로 표시한다.

섹션 상단 바는 연한 회색 배경과 하단 경계선을 가진다.

상단 바 왼쪽에는 `문의 목록` 제목을 표시한다.

상단 바 오른쪽에는 다음 요소를 가로로 배치한다.

- `총 N건`
- `엑셀 가져오기` 버튼
- `엑셀 내보내기` 버튼

모바일 폭에서는 상단 바 내부 요소가 세로로 자연스럽게 줄바꿈되어야 하며, 버튼들이 화면 밖으로 넘치지 않아야 한다.

`총 N건`은 작은 크기의 중간 회색 텍스트로 표시한다.

`엑셀 가져오기` 버튼은 흰색 배경, 회색 테두리, 진회색 굵은 글자로 표시한다. 마우스를 올리면 테두리와 글자색이 진한 파란색으로 바뀐다.

`엑셀 내보내기` 버튼은 진한 파란색 배경, 흰색 굵은 글자로 표시한다. 마우스를 올리면 더 어두운 파란색으로 바뀐다.

엑셀 상태 메시지는 상단 바 바로 아래에 표시한다. 기본 상태에서는 보이지 않아야 하며, 가져오기 또는 내보내기 동작 이후에만 나타난다.

문의 카드 목록은 상태 메시지 아래에 표시하며, 내부 여백 약 16px과 카드 간격 약 16px을 유지한다.

### 문의 카드

각 문의 카드는 흰색 배경, 옅은 회색 테두리, 약한 그림자, 8px 수준의 둥근 모서리로 표시한다.

카드 상단은 데스크톱 폭에서 좌측 정보 영역과 우측 `삭제` 버튼 영역으로 나뉜다.

좌측 정보 영역에는 위에서 아래 순서로 다음 요소를 표시한다.

1. 카테고리 배지와 상대 등록 시간
2. 문의 제목
3. 작성자

카테고리 배지와 상대 등록 시간은 같은 줄에 배치한다. 공간이 부족하면 줄바꿈이 가능해야 한다.

문의 제목은 진한 검정 계열 텍스트와 매우 굵은 두께로 표시한다.

작성자 줄은 제목 아래에 배치하며, 작은 크기와 중간 회색 텍스트를 사용한다.

`삭제` 버튼은 카드 오른쪽 상단에 배치한다. 모바일 폭에서는 문의 정보 아래쪽 또는 오른쪽 가능한 위치에 자연스럽게 배치하되, 버튼 크기가 줄어들어 텍스트가 잘리지 않아야 한다.

문의 본문은 카드 상단 정보 아래에 표시한다. 본문은 중간 진회색 텍스트로 표시하고, 줄 간격은 약 1.75배 수준으로 둔다.

## 5. 디자인 규칙

### 색상

주요 색상은 신뢰감 있는 파란색 계열과 흰색, 회색 계열을 사용한다.

- 기본 배경: 흰색
- 연한 섹션 배경: `#F8FAFC`에 가까운 매우 밝은 회청색
- 주요 파란색: `#1E40AF`에 가까운 진한 파란색
- 포커스 및 강조 하늘색: `#0EA5E9`에 가까운 밝은 하늘색
- 기본 본문 텍스트: 매우 진한 남색 또는 검정에 가까운 회색
- 보조 텍스트: 중간 회색
- 테두리: 옅은 회색
- 성공 상태 배경: 연한 하늘색
- 성공 상태 텍스트: 진한 파란색
- 오류 상태 배경: 연한 빨간색
- 오류 상태 텍스트: 진한 빨간색

### 타이포그래피

페이지 전체는 한글 가독성이 좋은 산세리프 글꼴을 사용한다. 우선순위는 `Pretendard`, `Noto Sans KR`, 시스템 산세리프 순서로 한다.

기본 글자 크기는 약 15px로 한다.

텍스트 위계는 다음 기준을 따른다.

- 페이지 제목: 가장 크고 굵게
- 섹션 제목: 페이지 제목보다 작지만 굵게
- 문의 제목: 본문보다 크거나 동일한 크기에서 매우 굵게
- 입력 라벨: 중간 굵기
- 보조 설명, 작성자, 시간, 총 건수: 작은 크기의 회색 텍스트

글자 간격은 기본값을 사용하며, 과도하게 좁히지 않는다.

### 간격과 모서리

콘텐츠는 화면 중앙의 제한된 폭 안에서 정돈되게 배치한다.

주요 박스, 버튼, 입력 필드, 문의 카드는 모두 약 8px 수준의 둥근 모서리를 사용한다.

섹션 내부 요소 사이에는 충분한 간격을 두어 입력 항목과 목록 카드가 서로 붙어 보이지 않게 한다.

카드와 카드 사이에는 약 16px 간격을 둔다.

### 반응형 규칙

모바일 화면에서는 다음 규칙을 따른다.

- 헤더와 메인 콘텐츠의 좌우 여백을 유지한다.
- `카테고리`와 `이름` 입력 필드는 세로로 쌓인다.
- 문의 작성 섹션의 보조 배지 `AI·DX 지원사업 상담`은 숨긴다.
- 문의 목록 상단의 제목, 총 건수, 엑셀 버튼들은 줄바꿈되어도 화면 너비를 넘지 않는다.
- 문의 카드의 정보 영역과 삭제 버튼은 좁은 화면에서도 겹치지 않는다.

데스크톱 화면에서는 다음 규칙을 따른다.

- 전체 콘텐츠는 중앙 정렬된 최대 너비 안에 배치한다.
- `카테고리`와 `이름`은 2열로 배치한다.
- 문의 목록 상단은 왼쪽 제목, 오른쪽 총 건수와 버튼 묶음으로 나뉜다.
- 문의 카드 상단은 왼쪽 문의 정보, 오른쪽 삭제 버튼으로 나뉜다.

### 인터랙션

입력 필드에 포커스가 들어오면 밝은 하늘색 테두리와 옅은 하늘색 링을 표시한다.

주요 버튼은 마우스 오버 시 색상 변화가 있어야 한다.

문의 등록, 삭제, 엑셀 가져오기, 엑셀 내보내기 결과는 별도 페이지 이동 없이 현재 화면에서 즉시 반영되어야 한다.

상대 시간 표시는 사용자가 페이지를 열어둔 상태에서도 약 30초 간격으로 갱신되어야 한다.

사용자가 입력한 제목, 작성자, 내용, 카테고리 텍스트는 화면에 표시될 때 HTML 태그로 실행되지 않고 일반 텍스트로 표시되어야 한다.

## 6. 성공 기준

이 웹페이지가 성공적으로 재현되었다고 판단하려면 다음 기준을 모두 만족해야 한다.

- 페이지 상단에 `부산 AI·DX 지원사업 문의 포털` 제목과 설명 문구가 정확히 표시된다.
- 첫 화면에서 `문의 작성` 섹션과 `문의 목록` 섹션이 모두 보인다.
- 문의 작성 폼에 카테고리, 이름, 제목, 내용 입력 항목과 `등록하기` 버튼이 있다.
- 카테고리 선택 항목 7개가 요구사항의 문구와 순서대로 제공된다.
- 초기 문의 목록에 샘플 문의 5건이 표시되고, `총 5건`이 표시된다.
- 샘플 문의의 제목, 작성자, 본문, 카테고리가 요구사항과 동일하게 표시된다.
- 새 문의를 등록하면 목록 최상단에 추가되고 총 건수가 1 증가한다.
- 등록 후 폼이 초기화되고 카테고리가 `AI·DX 솔루션 도입`으로 돌아간다.
- 각 문의 카드의 `삭제` 버튼을 누르면 해당 문의가 즉시 사라지고 총 건수가 감소한다.
- 모든 문의를 삭제하면 `등록된 문의가 없습니다.` 빈 상태 문구가 표시된다.
- `엑셀 내보내기`를 누르면 현재 문의 목록이 `문의_목록_YYYY-MM-DD.xlsx` 파일로 저장된다.
- 내보낸 엑셀 파일에는 `ID`, `카테고리`, `제목`, `작성자`, `내용`, `등록일시` 열이 이 순서대로 포함된다.
- `엑셀 가져오기`를 통해 유효한 문의 행을 추가할 수 있고, 추가된 문의가 목록에 표시된다.
- 엑셀 가져오기 또는 내보내기 후 성공·오류 상태 메시지가 요구사항의 문구와 색상 규칙에 맞게 표시된다.
- 모바일 폭에서 입력 필드, 버튼, 문의 카드 내용이 화면 밖으로 넘치거나 서로 겹치지 않는다.
- 데스크톱 폭에서 콘텐츠가 중앙의 제한된 폭 안에 정돈되어 표시된다.
- 입력 필드 포커스, 버튼 hover, 상대 시간 갱신 등 주요 인터랙션이 동작한다.
- 사용자가 입력한 HTML 형태의 문자열은 실제 HTML로 렌더링되지 않고 텍스트로 표시된다.
